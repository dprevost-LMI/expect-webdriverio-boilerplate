# expect-webdriverio Boilerplate

This is a boilerplate project for WebdriverIO leveraging the latest `expect-webdriverio` library.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

## Running Tests

Run the sample test:
```bash
npm test
```

## Features

- **WebdriverIO**: Latest version
- **expect-webdriverio**: Latest version for powerful assertions
- **TypeScript**: Fully typed tests
- **Mocha**: Test framework

## Configuration

The configuration is located in `wdio.conf.ts`.
